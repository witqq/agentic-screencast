# Agentic Screencast — точка входа для агента

Agentic Screencast — ваш инструмент для подготовки видеопрезентации человеку.
Изучите продукт, напишите сценарий, соберите MP4 и проверьте его. CLI создаёт
слайды, получает звук, рендерит веб-кадры и записывает реальные действия
Playwright через `agentic-screencast/capture`. Исследование, выбор материала
и приёмка результата остаются за агентом. Неизменные сцены используют кэш.

## Три правила, без которых легко сделать неверно

1. **Вход сборки один — файл сценария.** Слайды и данные сборки порождаются
   из него, лежат рядом с ним и правятся только через него. Руками их
   править бессмысленно: следующий запуск перезапишет. Живую видеосцену
   сначала запишите через Playwright capture и укажите её файл в сценарии.
2. **Длительность речевой сцены выводится из речи.** Речь делится на такты
   (абзац — такт), у каждого своя запись и своя длина; длина сцены — их
   сумма. Картинка следует за звуком, а не наоборот, поэтому смена голоса
   или темпа обесценивает и звук, и кадры — так и задумано. У немой
   видеосцены длительность задаёт клип; аннотации могут продлить её.
3. **Синтез сетевым движком стоит денег.** Ключ кэша звука — пара «текст
   такта плюс данные голоса»; изменив любую половину, вы платите за этот
   такт заново. Для проб есть движок `stub`: тишина нужной длины,
   ни сети, ни счёта. Чтобы озвучить своим голосом, есть `recorded`:
   он берёт записи из каталога и адресует их текстом реплики.

## Как запускать

Работайте в отдельном каталоге ролика. Для пробы выберите `stub`;
`--keys-only` тоже может синтезировать звук. Подробности — в `docs/moira.md`.

```bash
npx agentic-screencast build --source story.md --out draft.mp4 --voice-json '{"engine":"stub","name":"silent","cps":15}'
```

Для ведения задачи доступен `admin/agentic-screencast-video` в Moira; CLI автономен.
Проверяйте MP4 глазами: `check` и `order` не доказывают качества изображения.

`agentic-screencast record --source story.md` поднимает localhost-страницу для записи
голоса: микрофону браузера нужен защищённый контекст.

Доступна ссылка на `dist/agentic-screencast.js` в `PATH`; данные идут в cwd или
`AGENTIC_SCREENCAST_HOME`. Реальные действия снимайте через `capturePage`/`recordTake`:
`overlay.pointer` поверх видео не нажимает UI.
