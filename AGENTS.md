# Agentic Screencast — точка входа для агента

Инструмент собирает видео из данных: вы описываете сцены, он синтезирует
речь, считает кадры и склеивает файл. Записи экрана нет — каждый кадр
это снимок веб-страницы в назначенный момент времени, поэтому сборка
воспроизводима, а сцены пересобираются по отдельности.

## Три правила, без которых легко сделать неверно

1. **Вход один — файл сценария.** Слайды и данные сборки порождаются
   из него, лежат рядом с ним и правятся только через него. Руками их
   править бессмысленно: следующий запуск перезапишет.
2. **Длительность сцены выводится из речи.** Речь делится на такты
   (абзац — такт), у каждого своя запись и своя длина; длина сцены — их
   сумма. Картинка следует за звуком, а не наоборот, поэтому смена голоса
   или темпа обесценивает и звук, и кадры — так и задумано.
3. **Синтез сетевым движком стоит денег.** Ключ кэша звука — пара «текст
   такта плюс данные голоса»; изменив любую половину, вы платите за этот
   такт заново. Для проб есть движок `stub`: тишина нужной длины,
   ни сети, ни счёта. Чтобы озвучить своим голосом, есть `recorded`:
   он берёт записи из каталога и адресует их текстом реплики.

## Как запускать

```bash
npx agentic-screencast build --source story.md --out video.mp4
```

Записать озвучку голосом: `agentic-screencast record --source story.md` — поднимает
страницу на localhost, потому что микрофон браузер даёт только
в защищённом контексте.

Работает и через символическую ссылку на `dist/agentic-screencast.js` в `PATH`.
Каталог данных считается от текущего рабочего каталога либо задаётся
переменной `AGENTIC_SCREENCAST_HOME`.
