# Как участвовать в разработке Agentic Screencast

[English](CONTRIBUTING.md) | **Русский**

Перед изменением проверьте существующие задачи. Уязвимости сообщайте приватно по инструкции из [SECURITY.md](SECURITY.md).

## Рабочее окружение

Нужен Node.js 20 или новее. Установите закреплённые зависимости и Chromium:

```sh
npm ci
npx playwright install chromium
npm test
```

Файл сценария остаётся единственным рукописным источником слайдов и данных сборки. Каталоги `slides/`, `.generated-*.json`, `dist/`, `site/`, кэш, записи и видео порождаются командами; не правьте их вручную.

## Изменения

- Работайте в отдельной ветке. Код, тесты и документация одного логического изменения должны попасть в неё вместе.
- Сначала ищите подходящий provider, voice engine, schema, message или build primitive. Параллельный механизм оправдан только после такой проверки.
- Проверка должна отличать требуемое состояние от похожего неверного.
- Для автоматических прогонов используйте `stub`. Сетевой синтез речи стоит денег и в CI не запускается.
- Храните ключи в окружении. Не добавляйте настоящие аккаунты, токены, записи голоса, снимки закрытых страниц, персональные пути и диагностические журналы.
- Заголовок коммита пишите в повелительном наклонении с префиксом `feat:`, `fix:`, `docs:`, `test:`, `build:` или `chore:`.

Перед pull request выполните полный локальный gate:

```sh
npm test
npm run pack:check
npm run site:check
```

В pull request укажите команды и наблюдаемые результаты. Release, публикацию в npm и deployment выполняет maintainer по [инструкции выпуска](docs/RELEASING.md).
