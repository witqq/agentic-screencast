# Видеопрезентация с агентом и Moira

[English](moira.md)

Agentic Screencast — инструмент агента для сборки видео. Агент изучает продукт,
пишет сценарий, запускает команды, разбирает отчёты и проверяет готовый ролик.
Человек получает MP4. Moira задаёт шаги процесса и сохраняет прогресс;
сборка и озвучка выполняются в рабочем окружении агента.

## Как начать

Подключите production-сервер Moira по MCP к агенту с доступом к командной строке,
файлам и просмотру изображений. Для запуска нужен аккаунт Moira. Передайте задачу:

> Найди публичный процесс Agentic Screencast Video в Moira. Подготовь
> видеопрезентацию продукта [источник и редакция] для [аудитория].
> Цель — [что должен понять зритель], язык — [язык], длительность — около
> [число] секунд. Работай в отдельном каталоге. Сначала собери бесплатный
> черновик с тишиной. Платную озвучку и публикацию без разрешения не запускай.
> Проверяй самостоятельно и честно укажи ограничения проверки.
> Дочерние процессы не запускай.

Идентификатор — `admin/agentic-screencast-video`. Агент находит его через
`list`, вызывает `start` с `action: "prepare"`, затем исполняет полученную
попытку запуска через `action: "execute"`. Каждый шаг требует своего
`processId`, `attemptId` и ответа по схеме из директивы. Для продолжения
служит `session` с `action: "current_step"` и идентификатором выполнения.
После потерянного ответа новый процесс создавать не нужно.

[Определение процесса](../workflows/production/flows/agentic-screencast-video.json)
хранится в репозитории. Оно использует этапы существующего product-video:
проверку фактов, сценарий, материалы, черновик, озвучку, исправления и передачу.
Приватный исходный процесс сохранён без изменений.

## Рабочее окружение

Зафиксируйте цель, аудиторию, язык, длительность и редакцию продукта в
`task-brief.md`. Каталог ролика должен находиться вне активной рабочей копии
продукта. Процесс закрепляет CLI версии 1.0.1. Нужны Node.js 20+, Chromium
и поставляемые с пакетом ffmpeg/ffprobe:

```sh
npm install --save-exact agentic-screencast@1.0.1
npx --no-install playwright install chromium
npx --no-install agentic-screencast schema
npx --no-install agentic-screencast paths
```

В версии 1.0.1 финальная склейка запускается через shell. Используйте созданные
агентом пути из латинских букв, цифр, косой черты, дефиса, подчёркивания и точки.
Пробелы и специальные символы shell в путях не поддерживаются.
Не передавайте сборщику непроверенные пути из пользовательских данных.

Скопируйте [небольшой полный пример](../example/agent-video.md) в каталог ролика
как `story.md`. Сценарий — единственный редактируемый источник; слайды и
`.generated-pitch.json` создаются автоматически.

```sh
npx --no-install agentic-screencast scenes --source story.md
npx --no-install agentic-screencast build --source story.md \
  --voice-json '{"engine":"stub","name":"silent","cps":15}' --out draft.mp4
npx --no-install agentic-screencast check --source story.md
npx --no-install agentic-screencast order --source story.md
```

Stub создаёт тишину. Флаг `--keys-only` не собирает MP4, но **синтезирует
отсутствующий звук**. Бесплатная проба требует явного выбора stub.

## Проверка и исправления

По умолчанию агент проверяет результат сам и сообщает об этом. Независимый
режим `review_mode: independent` требует разрешённого отдельного исполнителя
или человека. В отчёте указываются SHA-256 проверенных файлов; до получения
отчёта по этим суммам файлы остаются неизменными. Если обязательная проверка
недоступна, процесс останавливается.

После правки сценария последующие результаты проверяются заново. Дефекты
материала и голоса возвращаются к своим этапам. Ошибка загрузки готового файла
не требует повторного рендера.

Команда `check` проверяет устоявшийся веб-кадр, а `order` — порядок элементов
при оценочной длительности тактов. Совпадение речи и изображения в финальном
видео они не доказывают. MHTML и видеовставки пропускаются командой `order`;
если проверять нечего, она возвращает код 2. Команда `check` видеовставки
не проверяет. Отразите охват в отчёте и просмотрите такой материал в MP4.
Полностью декодируйте файл, сверьте потоки и длительность, проверьте каждую сцену.

## Голос и разрешения

- `synth`: сначала изучите движок. Подтверждённый локальный синтез не требует
  разрешения на расходы. Сетевой движок или неизвестная стоимость требуют
  `allow_paid_synthesis: true` и согласованного объёма. Начните с короткой пробы.
- `human`: пользователь записывает текущие такты через локальную страницу.
  Дождитесь реальных файлов и соберите ролик движком `recorded`.
- `silent`: пользователь явно выбирает итоговое видео без речи.
  Отказ от платного синтеза не означает согласия на беззвучный результат.

Ключи не должны попадать в сценарий, данные голоса, ответы Moira или отчёты.
Читайте их только из разрешённых защищённых источников. Перед передачей снимков
проверьте видимые закрытые сведения: отсутствие cookie в MHTML их не исключает.

На выходе — исходный MP4, контрольная сумма, параметры видео, редакция продукта,
сценарий, материалы и отчёт с фактическим режимом проверки. В каталоге остаются
факты, результаты сборки и конфигурация голоса без секретов.

`allow_commit` разрешает только локальный коммит в указанной области.
`allow_external_delivery` — только согласованную операцию по конкретному адресу.
Оба разрешения по умолчанию выключены. Публичность процесса не разрешает
публиковать ролик пользователя. Сам CLI работает и без Moira.
