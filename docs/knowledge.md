# Find the knowledge for the creative question

This is the reading map for making a film. Start from the material, the audience and the change in understanding or feeling the film should create. Read the branch needed for that decision; the source documents remain the detailed knowledge, with their research, examples and limitations. This map adds no approval, worksheet or validation round.

| Creative question | Read | What you get |
| --- | --- | --- |
| What is this film about, and how does it develop? | [Scenario playbook](scenario-playbook.md) | Genre alternatives, argument and narrative development, evidence, hooks, endings and researched sources |
| What must the viewer understand at this moment? | [Directing](directing.md) | Identity, change, causality, location, comparison and staging alternatives |
| How do real components, code and events become understandable? | [Architecture films](architecture-films.md), [real-code example](../example/architecture-walkthrough/README.md) | Actual inputs/results, ownership, call paths, evolving content and alternatives |
| Can several actions work together? | [Combinations](combinations.md) | Attention hierarchy, causal timing, reading, continuity, speech and camera coordination |
| Which tools can stage the chosen explanation? | [Tools atlas](atlas.md), [directed scenes](directed-scenes.md), [motion vocabulary](motion-design.md), `help slides`, `help overlay`, `schema` | Report objects/actions, existing entrances, depth, backgrounds, text, camera and transitions; exact callable fields are in help/schema |
| Which mistakes obscure the explanation? | [Film craft](film-craft.md) | FC rules and concrete counterexamples; apply each rule within its stated scope |
| How should the image look? | [Visual design](visual-design.md), [theme tokens](theme-tokens.md) | Composition, type, spacing, palette, subject treatment and measured constraints |
| How do I frame for a phone? | [Vertical video](vertical-video.md), [whole-interface orientation](directed-scenes.md#show-the-whole-interface-before-a-detail) | Whole-to-detail UI context, safe zones, reading size and automatic conversion limits |
| What should I hear and read? | [Sound](sound.md), [subtitle research](research/subtitles.md), [font research](research/fonts.md) | Narration/music/accent hierarchy, source and licence records, competing evidence and typography |
| Where does the material come from? | [Visual assets](visual-assets.md), [reference](reference.md#recording-real-actions) | Real footage, local media, provenance and recording contracts |
| How do I operate the tool? | [Reference](reference.md), `help <topic>` | Single scenario input, providers, clocks, measured speech, builds and delivery |

Scenario, staging and tool choice are different decisions. A genre is not a layout. A layout is not a story. A technique demonstration is not a recommendation to use every technique in one film. Use the relevant evidence and recommendations to reason about your material, rather than choosing one recipe and filling its boxes.

Sources, conditions of measurement, conflicting findings and evidence limitations belong beside the facts they qualify. Timing guidance borrowed from interfaces describes an interaction context; a film may need a different reading hold. A measured parameter can inform staging without proving that staging is artistically effective.
