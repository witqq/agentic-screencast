# Agentic Screencast — все возможности и как их показать

Этот список перечисляет все возможности Agentic Screencast и отвечает на три вопроса: что делает
возможность, чем она включается и как показать её на экране — в ролике или на лендинге. Список
взят из самого инструмента: `agentic-screencast help` со всеми темами, `agentic-screencast schema`
(каждый вид сцены и каждое поле), список команд и API захвата. Скрипт `check-inventory.mjs` рядом
проверяет, что каждый вид, команда и поле здесь названы.

Последняя колонка говорит, показывает ли возможность лендинг на 2026-09-26
(`website/landing/report.md`):
- **да** — показана в клипе или описана;
- **устарело** — показана в прежнем виде или поведении;
- **текст** — только упомянута словами;
- **нет** — отсутствует.

В какой главе обзорного ролика (`website/overview/`) показана каждая возможность и какой её клип
станет примером на лендинге, записано в `clips.md`.

## 1. Один файл сценария — одна сборка

| Возможность | Чем включается | Как показать | Лендинг |
|---|---|---|---|
| Один текстовый файл делает весь ролик: шапка, сцены, речь прозой | `story.md`; `build` | файл прокручивается рядом с кадром, который из него получается | да |
| Абзац — такт со своей записью, длиной и ключом кэша; правка одной фразы пересобирает один такт | абзацы речи; `build --keys-only` | правка фразы и пересборка: в отчёте один такт не из кэша | текст |
| Произносимый вариант такта (строка `~`): на экране остаётся написанное | строка `~` | в субтитрах «API», голос читает «эй-пи-ай» | нет |
| Моменты по речи (якоря): `b2`, `b2+0.4`, `b2.end`, `40%` — картинка идёт за словами при смене голоса | `at`, `spotlight`, `at` в `overlay`, `stills`, `sfx`, `flash`, `shake`, `data-at` | одна сцена в двух темпах: карточки и наезды сдвигаются со словами | нет |
| Кэш: неизменная сцена не перерисовывается, картинки страницы учитываются | само | журнал сборки: «взята из кэша» при пересборке | нет |
| Одна сцена отдельно — тот же сегмент, что в ролике | `build --only` | — (рабочий инструмент) | нет |
| Отчёт сборки: начало и конец сцен, такты, кадры, отметки, звук, проверки, время; `audit` сверяет длину закодированных видео и звука и главы с тем, что ждала сборка | `<film>.report.json` | JSON рядом с роликом, предупреждения подсвечены | нет |
| Ошибки разбора называют строку и ближайшее имя («did you mean «title»?»); отказ сборки — одна строка | само | опечатка в терминале и ответ | нет |
| Длинные поля в несколько строк (блок, список, JSON) | `code: \|`, `items: \|` | — | нет |
| Тихий хвост после речи сцены | `tail` (в шапке и на сцене) | — | нет |
| Размер кадра, частота и качество кодирования | `frame`, `encode` | — | нет |
| Переводы в том же файле: `title.ru:`, блок речи `[ru]`, `page.ru:`, `file.ru:`, `voice.ru:` | `--lang ru` у build, lint, frames, script, scenes | один кадр на двух языках рядом | да |
| Непереведённые видимые поля называются | `lint --lang ru` (`untranslated`) | JSON lint с названным полем | текст |
| Язык ролика и правила чтения для синтеза | `lang`, `pronounce` | латиница, правильно прочитанная русским голосом | нет |

## 2. Виды сцен

Все слайды рисуются по часам сцены: любой кадр, снятый отдельно, равен тому же кадру полной сборки.

| Вид | Что показывает | Как показать | Лендинг |
|---|---|---|---|
| `slides.chapter` | открывает ролик или часть: `kicker`, набираемый `title`, `body`; `part` называет часть | начало каждой главы обзора | да |
| `slides.hero` | заголовок, поднимающийся по словам, `body`, картинка `image` за ним | начало обзора | да |
| `slides.steps` | пункты загораются один за другим вместе с речью | «три шага» создания ролика | да |
| `slides.features` | от двух до шести карточек переворачиваются, эмодзи | набор в шести карточках | да |
| `slides.timeline` | линия дорисовывается до каждой вехи | путь от просьбы до MP4 | да |
| `slides.counter` | цифры-одометр и кольцо процентов (`values`) | 24 семейства шрифтов, 12 переходов, 20 видов слайдов | да |
| `slides.number` | крупное число `value`, подпись `label`, `tags`; `count` off останавливает прокрутку | цель −14 LUFS | текст |
| `slides.compare` | две колонки (`left`, `right`) въезжают со своих сторон | таймлайн редактора против файла сценария | текст |
| `slides.chain` | узлы `nodes` появляются, стрелки дорисовываются; `back` — возврат | конвейер сборки | текст |
| `slides.quote` | цитаты проявляются шторкой | строка из базы знаний с источником | текст |
| `slides.beforeafter` | два состояния (`image`, `after`) и едущий разделитель, `labels`, `split` | старые и новые рукописные метки | да |
| `slides.parallax` | панели `panels`, вырезанные из снимка, висят на своей глубине | лист кадров в глубину | да |
| `slides.perspective` | снимок на экране в перспективе (WebGL): облёт, блик, отражение | страница лендинга на экране | да |
| `slides.chart` | столбцы растут или линия рисуется (`type`), пик `peak` загорается; данные из CSV, `data.ru` | ролики по неделям из CSV | да |
| `slides.code` | код набирается на месте со скоростью `cps`, строки файла `lines`, подсветка `highlight`, вкладка `name`; в вертикали переносится | набор самого сценария | да |
| `slides.photo` | медленный наезд `push` к точке `point` фотографии | кадр готового ролика | текст |
| `slides.shot` | снимок в браузере, телефоне или простой рамке, парит в 3D; высокий прокручивается | страница отчёта, прокрученная в браузере | текст |
| `slides.outro` | финальная карточка: заголовок, текст, кнопка (`cta`), адрес | призыв к действию | да |
| `slides.card` | карточка трейлера: одно-три слова врезаются, вспышка, тряска, искры | «ОДИН ФАЙЛ» в главе о трейлере | текст |
| `slides.titlecard` | название ролика разреженными капителями, из размытия, с бликом | название обзора | текст |
| `report` | отчёт, презентация или лендинг, которые agentic-report собирает из `report` заново для каждой сцены; камера наезжает на разделы по id | исходник лендинга, снятый раздел за разделом | нет |
| `page` | любая HTML-страница: сохранённая, порождённая или своя, её анимации по часам сцены; `target`, `mustRead`, `zoom`, `spotFrom`, `focus` | страница-схема, рисуемая по тактам | да |
| `page`, рисующая по речи | `window.renderAt(t)` и якоря `data-at` | схема, блоки которой появляются, когда их называют | нет |
| `video` | готовый клип или живой дубль: кусок `from`/`to`, `fit` contain или cover, `freezeAt`, `duration` | один дубль в нескольких сценах | да |
| Настройки слайдов любого вида | `text` (14 стилей фразы), `enter` (18 появлений), `move` drift/push/still, `background`, `align`, `at`, `count`, `note` | один слайд в трёх стилях | текст |
| Слайд вписывает себя до 72%; что не вписалось, названо в отчёте (`overflow`) | само | строка отчёта о слишком длинном слайде | нет |
| Свои виды сцен от внешнего поставщика | `providers` в шапке, `provider-check` | — (для разработчика) | нет |

## 3. Живая съёмка настоящего продукта

| Живой курсор: едет по дуге, наклоняется в движении, принимает форму элемента под ним (стрелка, рука, текстовый, захват), приседает и пружинит на настоящем pointerdown | само в дубле | крупно курсор, доезжающий до кнопки | устарело |
| Эффект клика | `click: "ripple" \| "spot" \| "echo"` | три клика — три эффекта | нет |
| Клавиши сочетаний на экране | `take.press` (`showKeys`) | появляется ⌘K | текст |
| Карточки поверх живой страницы | `take.card`, `withCard`, `withFocusCard` (reveal, motion) | карточка рядом с кнопкой, пока идёт действие | да |
| Фокус на живой странице настоящим CSS-увеличением | `focus`, `unfocus`, `withFocus` | страница работает под увеличением | да |
| Отметки: названные моменты и прямоугольники элементов | `take.mark(name[, locator])` → `@name` в сценарии | `freezeAt: @saved`, метка на `@total` | текст |
| Записанные действия и путь курсора | файл отметок (`path`, `actions`, `rects`) | — (основа autoZoom) | нет |

| Увеличенное окно следует за курсором | `autoZoom: {"follow":"cursor"}`, `follow` у камеры | длинное перетаскивание, за которым едет окно | нет |
| Чёткий дубль телефонного размера | `recordTake({viewport, scale})`; lint `take-small` | телефонная вёрстка, записанная в 1080×1920 | нет |
| Тема дубля совпадает со сценой | `recordTake({theme})`; lint `take-theme` | — | нет |
| Пустое начало обрезается, ошибка страницы роняет дубль | `trimStart`; само | — | нет |
| Снимки интерфейса как самодостаточные страницы | `agentic-screencast snapshot` | — | нет |

## 4. Камера и внимание

| Возможность | Чем включается | Как показать | Лендинг |
|---|---|---|---|
| Фокус одной строкой: наезд, затемнение, удержание до конца такта, переезд к следующему предмету | `spotlight: #a @ b2 \| #b @ b3` | камера обходит схему блок за блоком | да |
| Настройки фокуса: `until`, `scale`, `shape` circle, `blur`, `desaturate`, `card`, `ring`, `dim`, `keep`, `style` gentle/snappy, `pan`, `slow`/`stop` на видео, `el3` на слайде, смешанная цепочка | JSON фокуса | один предмет в трёх видах | текст |
| Чтение широкого предмета: `pan` наезжает до читаемости и ведёт вдоль | `"pan": true` | длинная строка таблицы, прочитанная на телефоне | нет |
| Подсветка без наезда | `"scale": 1` | весь экран на месте, одна кнопка в свете | нет |
| Ручные движения камеры над страницей или клипом | `overlay.camera` (area/target, move, hold, return) | — | текст |
| Время внутри кадра: замедление, разгон, дорисовка кадров, остановки | `speed` (`rate`, `ramp`, `interpolate`, `{at,hold}`), `freezeAt` | результат замирает, пока камера наезжает | да |
| Размытие движения камеры, удержания остаются резкими | `motionBlur` | кадр быстрого наезда: размытый против резкого | нет |
| Рамки устройств для клипа или снимка | `device: browser <url> \| phone \| frame` | один дубль в браузере, телефоне и простом окне | текст |
| Удары: вспышка и тряска | `flash`, `shake` | карточка трейлера врезается в кадр | нет |
| Лупа: увеличенный круг, пока камера стоит | `overlay.loupe` (`place`) | пик графика под лупой | да |
| Рукописные метки: круг, заходящий за начало, стрелка, подчёркивание — пером с сужающимися концами | `overlay.marks` | круг вокруг итога | устарело |
| Блики и всплески (конфетти, искры, с зерном) | `overlay.glints`, `overlay.bursts` | конфетти успеха | да |
| Вертикальное кадрирование: горизонтальную страницу или клип режет окно 9:16, идущее за фокусом и кликами; страница, которую не разрезать, называет свою вертикальную вёрстку | `--format vertical`, `pageVertical` | горизонтальный ролик и его вертикальная нарезка рядом | да |
