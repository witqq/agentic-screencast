# Видеопрезентации, которые собирает агент

**Укажите агенту продукт, аудиторию и то, что нужно объяснить. На выходе — видео для человека.**

Agentic Screencast — инструмент агента для сборки видео через командную строку. Агент изучает продукт, пишет сценарий и проверяет результат. Инструмент превращает сценарий в слайды, озвучку и MP4. Так можно подготовить объяснение продукта, обзор функции или презентацию с голосом.

Один текстовый источник. Машинно читаемые схемы и отчёты сборки позволяют проверять вход и результат; правки вносятся по сценам, без управления видеоредактором.

Слайды и данные сборки порождаются из сценария. Следующий запуск заменит их новой редакцией.

:::card{title="Кадры воспроизводимы"}

::::::section{title="Как сценарий агента становится видео" id="pipeline" nav="Сборка" composition="split" surface="grid" transition="reveal" scene="progress"}
:::lead
Агент описывает сцены и речь в одном файле. Сборка измеряет звук и подстраивает под него изображение. Неизменные сцены берутся из кэша; после правки такта пересобираются связанные звук и кадры.
:::

::::timeline{title="Сборка сцены" description="Каждый этап оставляет результат, который проверяет следующий."}
:::event{date="Разбор" title="Прочитать сценарий" kind="neutral"}
Неизвестный вид сцены, поле, обязательное значение или якорь времени останавливают работу до рендера.
:::
:::event{date="Речь" title="Измерить каждый такт" kind="accent"}
Можно получить тишину, синтезировать речь или взять человеческую запись и привести её к WAV 48 кГц моно.
:::
:::event{date="Рендер" title="Перейти к нужному моменту страницы" kind="success"}
Chromium получает явные часы. Сохранённая страница приложения может открываться с заблокированной сетью.
:::
:::event{date="Склейка" title="Собрать видео" kind="warning"}
Сцены приводятся к общему размеру и частоте кадров, затем соединяются со звуком.
:::

::::::section{title="Используйте готовый материал" id="material" nav="Материал" composition="mosaic" surface="mesh" transition="stagger"}

::::cards
:::card{title="Встроенные слайды"}
Сравнение, цепочка, крупное число и цитата подходят для короткого объяснения продукта.
:::
:::card{title="Сохранённые страницы"}
Клиентское приложение снимается в MHTML. Сценарий называет точный элемент для увеличения и фокуса.
:::
:::card{title="Готовое видео"}
Клип встаёт в общий таймлайн; сборка приводит его к размеру кадра и длительности речи.
:::
:::card{title="Внешние поставщики"}
Новые виды сцен добавляются на любом языке через JSON-контракт. Поставляемая команда проверяет его исполнение.
:::
::::

:::decision{title="Ядро не хранит список видов сцен"}
Поставщик материала объявляет поля, обязательные значения, эффекты и пороги качества. Этот контракт читают разбор, схема, генератор и проверка.
:::

::::::section{title="Запишите свой голос, не меняя сборку" id="voice" nav="Голос" composition="stage" surface="glow" tone="accent"}
:::lead
Страница записи работает на локальном адресе: там браузер разрешает доступ к микрофону. Каждый файл адресуется текстом такта и хранится вне репозитория.
:::

```sh
agentic-screencast record --source story.md
agentic-screencast build --source story.md --out product-tour.mp4 --voice-json '{"engine":"recorded"}'
```

::::cards
:::card{title="Бесплатная проверка"}
Движок `stub` создаёт тишину предсказуемой длины и не обращается к сети.
:::
:::card{title="Записанная речь"}
Замена WAV меняет отпечаток содержимого и обесценивает связанный кэш.
:::
:::card{title="Внешний синтез"}
Движок получает текст и данные голоса через документированный контракт; ключи остаются в окружении.
:::

::::::section{title="Проверьте то, о чём успешная сборка не судит" id="verification" nav="Проверка" composition="stack" surface="grid"}

| Команда | Наблюдаемый результат |
|---|---|
| `check` | Объявленное содержимое найдено, помещается в кадр, читается и проходит пороги поставщика. |
| `order` | Элементы появляются по порядку на своих тактах или временных якорях. |
| `verify` | Повторные кадры совпадают, движение меняет их, замороженное время стоит, а переход воспроизводит сквозной рендер. |
| `voice-check` | Голосовая программа возвращает JSON, коды отказа, устойчивый отпечаток и WAV 48 кГц моно. |
| `provider-check` | Поставщик объявляет допустимые виды и создаёт страницу либо явно отказывает. |

:::callout{kind="info" title="Сборка и приёмка разделены"}
`build` отдаёт запрошенное видео. Проверки изображения и порядка запускаются там, где проект требует этих гарантий.
Они используют оценочное время тактов. Совпадение изображения с финальной речью проверяйте в самом MP4; видеовставки требуют прямого просмотра.
:::
::::::

::::::section{title="Проведите агента через всю задачу с Moira" id="moira" nav="Moira" composition="split" surface="grid" transition="reveal"}
:::lead
Публичный процесс Agentic Screencast Video включает факты, сценарий, материалы, бесплатный черновик, озвучку и проверку. Замечания возвращаются на тот этап, где их можно исправить.
:::

Moira выдаёт инструкции и сохраняет прогресс. Команды запускает агент в своём окружении; там же он проверяет MP4. Самостоятельная проверка отмечается явно. Для независимой нужен доступный исполнитель и разрешение на его участие. Платная речь и внешняя передача требуют отдельных разрешений.

Попросите агента найти `admin/agentic-screencast-video` в подключённом каталоге Moira. Нужны аккаунт Moira и агент с доступом к локальным файлам и командной строке. Сам CLI работает и без Moira.

::::::section{title="Первый ролик вашего агента" id="start" nav="Старт" composition="stage" surface="mesh" tone="contrast" align="center"}

Поручите агенту объяснить продукт выбранной аудитории; укажите язык и ориентир длительности. Начните с бесплатного черновика с тишиной. Перед запуском скопируйте полный пример по ссылке ниже в отдельный каталог ролика как `story.md`.

```sh
npm install --save-exact agentic-screencast@1.0.1
npx --no-install playwright install chromium

npx --no-install agentic-screencast build \
  --source story.md \
  --voice-json '{"engine":"stub","name":"silent","cps":15}' \
  --out draft.mp4
```

Stub создаёт тишину. Флаг `--keys-only` не собирает MP4, но может синтезировать отсутствующий звук. Для бесплатной проверки явно выбирайте stub. Допустимые пути и ограничения проверки версии 1.0.1 описаны в инструкции.

::::::section{title="Явная локальная граница доверия" id="boundaries" nav="Границы" composition="stack" surface="grain"}

В поставку входят разбор сценария, встроенные и внешние поставщики материала, движки голоса, запись речи, детерминированный рендер Chromium, сборка ffmpeg, кэш и исполняемые проверки контрактов.

Инструмент не записывает живой экран, не выбирает голос за автора, не оценивает убедительность сценария, не защищает от намеренно запущенной непроверенной команды и не публикует видео самостоятельно.

:::disclosure{title="Где держать ключи" open="false"}
Движок голоса и снимок страницы читают ключи из окружения или игнорируемого `.env`. Не помещайте ключ в данные голоса: они входят в адрес кэша и отчёт сборки.
:::

Agentic Screencast распространяется по GPL-3.0-or-later: рабочая зависимость включает GPL-версию ffmpeg. Точный граф зависимостей и сторонние лицензии также зафиксированы в репозитории.
::::::
