# Security Policy

**English** | [Русский](SECURITY.ru.md)

## Supported version

Security fixes are provided for the latest published version.

## Report a vulnerability

Do not publish vulnerability details in a GitHub issue. Open a private [GitHub Security Advisory](https://github.com/witqq/agentic-screencast/security/advisories/new).

Include the affected version, reproduction conditions, expected impact, and the smallest safe example. Remove credentials, personal information, recordings, authenticated page captures, and unrelated logs before attaching evidence.

The project executes explicitly configured voice engines and material providers as local programs. Running an untrusted provider, voice command, scenario, saved page, or video file is outside the trusted-input boundary. A report should distinguish behavior caused by trusted Agentic Screencast code from behavior of an intentionally executed third-party program or untrusted content.
